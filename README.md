# 현장 MSDS · 경고표지 스튜디오

참고 사이트 코드를 사용하지 않고 독립 구현한 정적 웹앱입니다. 서버·유료 API 없이 브라우저에서 작동합니다.

## GitHub 업로드
1. ZIP 압축을 풉니다.
2. 새 GitHub 저장소를 만들거나, 기존 저장소를 먼저 백업합니다. 다른 개발자의 사이트와 별도 저장소 사용을 권장합니다.
3. `msds-studio` 폴더 안의 **모든 파일과 assets/vendor 폴더**를 저장소 최상위에 업로드합니다. index.html이 최상위에 있어야 합니다.
4. Settings → Pages → Deploy from a branch → main / root를 선택하고 저장합니다.
5. 게시가 완료되면 해당 github.io 주소를 엽니다. 제품 QR의 게시 주소에 이 주소를 입력합니다.
6. 현재 파일을 바로 열기(file://)보다 GitHub Pages 또는 로컬 HTTP 서버로 여는 것을 권장합니다. PDF worker / 데이터 fetch가 file://에서 제한될 수 있습니다.

## 작업 순서
- 텍스트형 PDF(여러 개 가능, 파일당 30MB 이하)를 올립니다. 앞쪽 12페이지만 읽습니다.
- 제품명을 선택하고 MSDS 제1·2항과 추출 내용을 대조합니다. 제품명이 없으면 직접 입력합니다.
- **그림문자는 GHS 코드가 텍스트로 있을 때만 자동 선택**합니다. 이미지로 들어 있는 경우 원문을 보고 직접 선택합니다. 신호어·H/P 문구 추출도 문서 형식에 따라 달라집니다.
- 텍스트에 코드가 없거나 표가 복잡하면 문구가 추출되지 않을 수 있습니다. 추출 원문을 보며 각 입력란에 원문 문구를 입력합니다.
- 규격·용량에 맞는 크기를 지정합니다. 규격 자동 적합 판정은 제공하지 않습니다.
- 공급자명·주소·전화번호 등 필수 입력을 채우고 원문·규격 확인에 체크한 후 출력합니다.
- PDF/PNG는 300dpi로 생성합니다. PDF는 A4에 반복 배치하거나, A4보다 크면 표지 실제 크기 페이지로 생성합니다. 인쇄는 100% 배율로 확인합니다.
- 엑셀은 **편집용 항목 표**이며 표지와 같은 레이아웃은 아닙니다. 그림문자는 코드·이름으로 표시합니다.
- 입력 내용은 이 브라우저 localStorage에 저장됩니다. PDF 원본 자체는 보관하지 않습니다. 작업 백업 버튼으로 JSON 백업을 수시로 받으세요. 다른 PC에서 자동 동기화되지 않습니다.

## 다국어 QR
1. 제품의 고정 ID는 유지합니다.
2. 언어별 제품명·신호어·유해 문구·예방 문구 번역을 입력하고 검토 여부를 표시합니다. 번역 자동 생성이나 기계번역 API는 없습니다.
3. 게시 주소에 본인 사이트의 폴더 주소(끝 `/`)를 입력합니다.
4. 제품 데이터 다운로드로 받은 `products.json`을 GitHub의 index.html과 같은 위치에 올립니다. 전체 작업 목록 중 이름 있는 제품이 게시됩니다.
5. ‘표지에 다국어 QR 넣기’를 체크합니다. 휴대폰에서 실제 QR을 열어 확인하고 인쇄합니다.
6. 추후 수정은 같은 ID로 편집 → products.json 재업로드. GitHub 주소와 ID가 같으면 QR은 유지됩니다. 게시 데이터는 누구나 조회할 수 있습니다. 원문 추출 텍스트는 게시 파일에서 제외합니다.
7. 등록하지 않은 번역은 해당 항목의 한국어 원문과 번역 미등록 안내를 표시합니다. 부분 번역도 안내합니다. 공급자 정보는 원문을 그대로 유지합니다.
8. 다른 PC로 옮기기 전 작업 백업을 받으세요. 작업 백업/기존 products.json을 ‘백업 복원’으로 병합할 수 있습니다. **다른 PC의 목록을 복원 없이 게시하면 기존 게시 제품이 빠질 수 있습니다.**

## 지원 범위와 제한
- OCR, AI 추출, 물질명 기반 자동 유해성 분류는 없습니다.
- 복잡한 다단 PDF·스캔·암호화·글꼴 매핑 문제는 수동 보완이 필요합니다.
- 원문의 문구를 자동 축약하거나 법정 예방조치 6개를 자동 선정하지 않습니다.
- 용량별 최소 면적·그림문자 우선순위·크기를 자동 판정하지 않습니다. 최종 규격은 고시 제6~8조·별표3 및 제조사 MSDS로 확인합니다.
- ‘없음’을 선택한 신호어/그림문자는 원문에서 실제로 해당하지 않는 경우에만 사용합니다.
- 텍스트로 입력한 공급자 전화번호는 긴급전화 여부를 자동 확인하지 않습니다.
- 예시 산소는 사용 흐름을 확인하는 연습용입니다. 실제 제품에 부착하지 마세요.
- 전체 제품 일괄 PDF/엑셀 출력, 자유 양식 편집은 이번 버전에 포함하지 않습니다. 제품별 출력 및 동일 제품 수량 지정은 지원합니다.

## 기준과 출처
- 국가법령정보센터: https://www.law.go.kr/admRulInfoP.do?admRulSeq=2100000278320
  고용노동부고시 제2026-26호(2026.4.24.) 확인일 2026-11-06. 이 앱은 적합성 인증을 하지 않습니다.
- GHS 그림문자: Wikimedia Commons의 표준 GHS 그림문자(SVG), UNECE GHS 도안에 따른 공개 표준 기호.
  원 출처 안내: https://unece.org/transport/dangerous-goods/ghs-pictograms

## 코드·라이브러리
- 신규 app.js, core.js, viewer.js, HTML, CSS: 현장용 사용·수정 가능. 원본 참고 사이트의 코드·문구 사전·레이아웃은 복제하지 않았습니다.
- pdf.js 3.11.174 (Apache-2.0), html2canvas 1.4.1 (MIT), jsPDF 2.5.1 (MIT), ExcelJS 4.4.0 (MIT), qrcode-generator 1.4.4 (MIT).
- 한국어 PDF용 CMap 및 기본 글꼴을 포함합니다. 그 밖의 언어 전용 CMap이 필요한 PDF는 직접 입력으로 보완하세요.
- vendor/의 라이브러리는 함께 배포되어 외부 CDN을 호출하지 않습니다. 라이선스 고지는 THIRD_PARTY.md 및 vendor/licenses/ 참조.

## v1.4 변경 (2026-11-06)
- 화면: ‘내용 입력·수정’과 ‘완성된 경고표지’ 2단 구성(모바일은 세로). 원본 PDF 미리보기 패널을 없애고 ‘원본 파일 열기’ 버튼만 제공합니다.
- 표 양식 표지: 명칭 → 그림문자·신호어 → 유해·위험 문구 → 예방조치 문구 → 공급자 정보 → (생략 시) MSDS 참고 문구.
- 용기 용량(mL·L·g·kg) 입력 시 고시 별표 3 구간·최소 면적을 계산하고 실제 면적과 비교합니다. 5ℓ 미만은 측면 표면적 입력이 필요하며, 질량 단위는 구간을 판정하지 않습니다. 추천 크기는 프로그램 추천값입니다.
- ‘표시사항 점검’ 패널: 충족/미충족/확인 필요/해당 없음, 자동 계산과 사람 대조 항목을 구분합니다. 법적 적합성 보장이 아닙니다.
- 예방조치 문구 표(체크·분류·코드·문구), 7개 이상일 때만 6개 표시, 범주 누락 안내, 포함·중복 코드 표시.
- 그림문자: 원문 텍스트/이미지 인식/H 코드 추정을 구분하고, 추정은 자동 선택하지 않습니다. 감탄부호 생략은 근거 H 코드로 판단합니다.
- PDF 배치: A4 세로·가로 여러 장 또는 표지 크기 용지, 여백·간격 지정, 축소 없음. 미충족 항목이 있으면 워터마크 초안만 저장됩니다.
- 하단 ‘작성 근거 및 적용 기준’에서 확인한 법령·고시와 미확인 자료를 확인하세요. 기준 데이터는 `standards-data.js`에서 관리합니다.
